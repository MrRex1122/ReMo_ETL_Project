⚙️ ОСНОВНОЙ АЛГОРИТМ

```
1. Загрузить Excel (столбец B)
   ↓
2. Для каждой позиции:
   a) Проверить кэш (быстро)
   b) Если не в кэше → Gemini API (точно)
      - Отправить запрос: "Найди этот товар в каталоге"
      - Получить JSON ответ: {name, article, confidence}
   c) Вернуть (найденное имя, цена, артикул)
   d) Сохранить в кэш
   ↓
3. Заполнить таблицу (столбцы G, H, I)
   ↓
4. Экспортировать в Excel
```

   ```python
   # Первый способ: одну позицию
   result = matcher.match("Кабель медный 4кв.мм")

   # Второй способ: целый файл
   df, stats = matcher.process_excel("input.xlsx", "output.xlsx")

   ```

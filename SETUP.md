# 🚀 Инструкция: Первоначальная установка ReMo Matcher

## Шаг 1: Получение API ключа Gemini

### 1.1 Переходим на https://aistudio.google.com/app/apikey

### 1.2 Авторизуемся с Google аккаунтом (если еще не авторизованы)

### 1.3 Нажимаем "Create API Key"

```
[Выбираем проект или создаем новый]
    ↓
[Create API Key in new project]
    ↓
[Copy] ← Скопировать ключ
```

### 1.4 Копируем полный ключ (выглядит так):
```
AIzaSyD_U_K1Z-J_Z_K1Z-J_Z_K1Z_7_K1Z...
```

## Шаг 2: Установка РЕПОЗИТОРИЯ

```bash
# Переходим в папку проекта
cd "<путь_к_проекту>\\ReMo_ETL_Project"

# Создаем виртуальное окружение (опционально, но рекомендуется)
python -m venv venv

```

## Шаг 3: Установка зависимостей

```bash
# Убедиться что virtual env активирован (должна быть (venv) в начале знака приглашения)
pip install -r requirements.txt
```

Процесс займет 1-2 минуты. Проверить установку:

```bash
python -c "import pandas, streamlit; from google import genai; print('✓ All packages installed')"
```

Вывод должен быть:
```
✓ All packages installed
```

## Шаг 4: Конфигурация API ключа

### Вариант A: Streamlit secrets (РЕКОМЕНДУЕТСЯ)

1. Открыть файл `.streamlit/secrets.toml` в текстовом редакторе

2. Заменить строку:
   ```toml
   GEMINI_API_KEY = "ваш_ключ_здесь"
   ```
   
   На вашу скопированную значение:
   ```toml
   GEMINI_API_KEY = "AIzaSyD_U_K1Z_J_Z_K1Z_J_Z_K1Z_7_K1Z..."
   ```

3. Сохранить файл (Ctrl+S)

### Вариант B: Переменная окружения (PowerShell)

1. Открыть PowerShell

2. Выполнить команду:
   ```powershell
   $env:GEMINI_API_KEY = "AIzaSyD_U_K1Z_J_Z_K1Z_J_Z_K1Z_7_K1Z..."
   ```

3. Убедиться что переменная установлена:
   ```powershell
   echo $env:GEMINI_API_KEY
   ```
   
   Должно вывести ваш ключ

## Шаг 5: Проверка данных

Убедиться что товарная база находится в правильном месте:

```powershell
Test-Path "<путь_к_данным>\\price_clean.csv"
```

Вывод должен быть `True`.

Если БД находится в другом месте, задайте путь через переменную:

```powershell
$env:REMO_DB_CSV = "<путь_к_данным>\\price_clean.csv"
```

Если файл не найден - запустить ETL:

```bash
python etl_pipeline.py
```

```bash

```

```

  Local URL: <local-url>

  For better performance, install Watchdog.
```

Если браузер не открылся - скопировать URL в адресную строку вручную.

## 🐛 Если что-то не работает

### 1. API ключ не работает

```
❌ GEMINI_API_KEY не установлен!
```

**Решение:**
- Проверить что файл `.streamlit/secrets.toml` существует
- Убедиться что ключ скопирован полностью (начинается с "AIza")
- Перезагрузить приложение: `Ctrl+C` → `streamlit run app.py`

### 2. Модуль не найден

```
❌ ModuleNotFoundError: No module named 'google'
```

**Решение:**
```bash
pip install google-genai --upgrade
```

### 3. Файл price_clean.csv не найден

```
❌ FileNotFoundError: ...\price_clean.csv
```

**Решение:**
```bash
# Запустить ETL для создания файла
python etl_pipeline.py
```

Или указать явный путь:

```powershell
$env:REMO_DB_CSV = "<путь_к_данным>\\price_clean.csv"
```

### 4. Ошибка подключения к Gemini

```
❌ Error: Failed to authenticate with Gemini API
```

**Решение:**
1. Проверить API ключ на https://aistudio.google.com/app/apikey
2. Убедиться что Internet соединение активно
3. Подождать 1-2 минуты и повторить

# Деплой ReMo Matcher на Railway

Ниже самый простой и рабочий сценарий для вашего проекта.

## 1) Подготовка репозитория

В проекте уже есть `Dockerfile`, поэтому Railway может собирать и запускать сервис как контейнер.

## 2) Создание проекта в Railway

1. Зайдите в https://railway.app
2. `New Project` -> `Deploy from GitHub repo`
3. Выберите репозиторий `ReMo_ETL_Project`
4. Railway автоматически обнаружит `Dockerfile` и создаст сервис

## 3) Переменные окружения (обязательно)

В сервисе Railway откройте `Variables` и добавьте:

- `GEMINI_API_KEY` = ваш ключ Gemini

(Опционально можно добавить и ваши `REMO_*` переменные путей, если нужны кастомные пути.)

## 4) Порт и запуск

Railway передаёт порт в переменной `PORT`, а в нашем Dockerfile уже указан запуск Streamlit на `8501`.

Для Railway лучше использовать динамический порт. Если хотите полностью корректно для cloud-runner, поменяйте команду запуска на вариант с `PORT`:

```dockerfile
CMD ["sh", "-c", "streamlit run app.py --server.address=0.0.0.0 --server.port=${PORT:-8501}"]
```

> Сейчас проект поднимается на `8501`. На Railway это обычно тоже работает при корректной настройке сервиса, но динамический `PORT` — более надёжный вариант.

## 5) Автодеплой из GitHub

По умолчанию Railway будет автоматически деплоить каждый push в выбранную ветку (обычно `main`).

## 6) Как сделать «деплой только после тестов»

Рекомендуемый способ:

1. Оставить GitHub Actions тесты (`pytest -q`) как обязательный check.
2. В GitHub включить Branch protection для `main`:
   - `Require a pull request before merging`
   - `Require status checks to pass before merging`
   - выбрать workflow с тестами
3. В `main` попадает только код с зелёными тестами.
4. Railway автодеплоит обновлённый `main`.

Итог: фактически деплой происходит только после прохождения тестов.

## 7) Проверка

После первого деплоя Railway даст публичный URL сервиса вида:

- `https://<service>.up.railway.app`

Откройте URL и проверьте, что интерфейс Streamlit доступен.

## 8) Частые проблемы

- **Ошибка старта контейнера**: проверьте логи Railway, что приложение слушает `0.0.0.0`.
- **Не видит GEMINI_API_KEY**: проверьте переменные в `Variables` и redeploy.
- **Долгий cold start**: для Streamlit нормально, особенно на бесплатном/минимальном тарифе.
